## Local Setup

1. Copy `.env.example` to `.env`.
2. Replace the two values with the Supabase project URL and publishable key from **Project Settings > API**.
3. Run `npm install` and `npm run dev`.

The `.env` file is ignored by Git. Never commit a Supabase service-role or secret key.
